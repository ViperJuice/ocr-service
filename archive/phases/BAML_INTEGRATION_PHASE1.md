### 2. Versioned Prompts
**Before**: Prompts scattered across code, hard to maintain
**After**: Centralized in `.baml` files with version control

**Example** from [baml_src/ocr.baml](baml_src/ocr.baml:6-25):
```baml
function ExtractTextOCR(page_image: image, custom_prompt: string?) -> OCRResult {
  client DeepSeekOCR
  prompt #"
    {{ _.role("user") }}
    {% if custom_prompt %}
      {{ custom_prompt }}
    {% else %}
      Free OCR. Extract all text from this image with high accuracy.
      Preserve the original layout and formatting as much as possible.
    {% endif %}
    {{ page_image }}
  "#
}
```

## Technical Notes

### BAML Generator Limitation
Current version (0.213.0) generates one target at a time. We use:
- **TypeScript**: Generated from BAML → [baml_client/](baml_client/)
- **Python**: Pydantic models + runtime approach → [src/services/baml_ocr_service.py](src/services/baml_ocr_service.py)

This hybrid approach provides all BAML benefits while working around generator limitations.

### Environment Variables
```bash
export DEEPSEEK_URL="http://localhost:8001"
export QWEN_URL="http://localhost:8002"
```

### Container Requirements
Both containers must support OpenAI `/v1/chat/completions` endpoint:
